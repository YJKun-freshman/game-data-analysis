# 🎮 遊戲數據分析作品集 (Game Data Analysis Portfolio)

歡迎來到我的數據分析作品集！本倉庫包含兩個獨立的數據分析專案，展示了如何運用 **SQL 的資料交叉核對邏輯**、**Python (Pandas) 的資料清理與特徵工程**，將原始數據轉化為具體的商業營運與行銷決策建議。

---

## 📊 專案一：手遊玩家付費行為分析 (`game_analysis.ipynb`)
本分析針對手遊玩家的付費流水帳進行深入研究，探討不同年齡層、遊戲類型、付費時機對付費金額的影響，並提供精準行銷與變現模式建議。

*   **數據規模：** 採用 Kaggle 3,024 筆真實玩家行為與付費數據。
*   **核心技術：** 
    *   **資料前處理：** 使用 Pandas 檢查資料結構、剔除重複廣告點擊與異常邏輯數據（Data QA）。
    *   **特徵工程：** 運用 `pd.cut` 將連續型變數（年齡、付費天數）進行商業意義分組。
    *   **數據統計：** 透過 `groupby`、`mean` 等聚合函數進行多維度交叉分析，並以 Matplotlib 繪製視覺化圖表。
*   **關鍵商業洞察：**
    1.  **高價值用戶：** 35-50 歲玩家平均付費金額最高（$124），消費力為 18-25 歲的 2.1 倍，且男性明顯高於女性。
    2.  **變現黃金視窗：** 安裝後 **8-15 天** 首次付費者的平均消費最高（$123），打破「越快推送越好」的迷思。
    3.  **品類變現潛力：** Racing 與 Battle Royale 付費最高，Action RPG 與 Sandbox 則墊底。

## 📈 專案二：遊戲平台廣告版位效益分析 (`platform_ad_analysis.ipynb`)
本分析聚焦於跨管道流量與廣告版位成效稽核，評估各個廣告來源的點擊轉換率與投資報酬率（ROI）。

*   **核心技術：** 
    *   運用類似 SQL `JOIN` 的邏輯進行多表欄位串聯與交叉比對。
    *   監控每日流量管線指標，排查異常點擊與低效版位（對接數據品質稽核實務）。
*   **關鍵商業洞察：**
    *   精準抓出曝光量高但轉換率（CVR）極低的「無效版位」，並提供重新分配廠商預算之量化建議，確保營運效益最大化。
